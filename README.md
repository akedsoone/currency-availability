# Мониторинг наличия иностранной валюты

Учебное веб-приложение для просмотра наличия иностранной валюты в кассах банковских отделений. Оно показывает текущее наличие, историю изменений и долю времени, в течение которого наблюдался каждый уровень.

## Возможности

- Фильтры по городу и валюте, поиск отделения по названию или адресу.
- Четыре уровня наличия: нет валюты, мало, достаточно, много.
- График за день, неделю и месяц. Он открывается рядом со списком после выбора отделения.
- Статистика по отделению, валюте и периоду. Доля каждого уровня рассчитывается от общей длительности выбранного периода. Пропуски замеров учитываются отдельно как «Нет данных».

## Как запустить

Понадобятся .NET 10 SDK и Docker с Docker Compose. Запустите Docker и выполните команды из папки проекта:

```powershell
docker compose up -d --wait
dotnet run
```

При первом запуске приложение создаст таблицы PostgreSQL и заполнит демонстрационную историю за 30 дней.

Источником данных служит локальный демо-API. Фоновая служба запрашивает данные при старте и затем каждые пять минут.

## Как проверить приложение

1. На главной странице выберите город и валюту.
2. Нажмите на карточку отделения и переключите период графика.
3. Откройте раздел **Статистика** и посмотрите распределение уровней наличия.

## База данных

| Таблица | Содержимое |
| --- | --- |
| `Cities` | Города |
| `Departments` | Названия и адреса отделений, коды в API, ссылки на города |
| `Currencies` | Коды и названия валют |
| `AvailabilityRecords` | Отделение, валюта, уровень наличия и время замера |

**Технологии:** C#, ASP.NET Core MVC, Razor, Entity Framework Core, PostgreSQL и JavaScript.
